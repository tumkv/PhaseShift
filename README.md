# 🌀 PhaseShift

**PhaseShift** — это 2D portal puzzle platformer на **MonoGame / C#**, вдохновлённый механиками порталов, физики и головоломок.  
Игрок проходит уровни, ставит синий и оранжевый порталы, использует кубы, кнопки, двери, ловушки и электрические зоны, чтобы добраться до выхода.

---

## 🎮 Игровой процесс

В игре нужно проходить уровни, используя портальную пушку и окружение.

| Механика | Описание |
|---|---|
| 🌀 Порталы | Ставьте синий и оранжевый порталы на подходящие поверхности |
| 🧍 Игрок | Двигается, прыгает и сохраняет инерцию при выходе из порталов |
| 📦 Куб | Можно поднимать, переносить и использовать для нажатия кнопок |
| 🔘 Кнопка | Открывает дверь, пока на неё давит игрок или куб |
| 🚪 Дверь | Блокирует путь и открывается от кнопки |
| ⚡ Электричество | Периодически включается и выключается, убивает игрока при касании |
| 🔺 Шипы | Опасные зоны, при касании уровень перезапускается |
| 🪤 Движущаяся ловушка | Платформа с шипами, которая движется вверх и вниз |

---

## 🧩 Уровни

В игре есть **6 уровней**, каждый из которых постепенно добавляет новые механики.

| Уровень | Особенность |
|---|---|
| 1 | Обучение управлению и базовым порталам |
| 2 | Пространственные головоломки с блоками |
| 3 | Движущаяся платформа с шипами |
| 4 | Электрические зоны с таймером |
| 5 | Куб, кнопка и дверь |
| 6 | Комбинация кнопки, двери и порталов |

---

## 🕹️ Управление

| Действие | Клавиша |
|---|---|
| Движение влево / вправо | `A` / `D` |
| Прыжок | `Space` |
| Поставить синий портал | Левая кнопка мыши |
| Поставить оранжевый портал | Правая кнопка мыши |
| Взять / отпустить куб | `E` |
| Сбросить порталы | `R` |
| Пауза / снять паузу | `Esc` |

---

## 🧠 Основные правила

1. Для прохождения уровня нужно добраться до зелёного выхода.
2. Порталы можно ставить только на разрешённые поверхности.
3. Нельзя ставить порталы:
   - на двери;
   - на кнопки;
   - на электрические зоны;
   - на движущиеся ловушки;
   - внутрь фоновых блоков;
   - на самый край платформы.
4. Куб можно использовать для удержания кнопки.
5. При падении, касании шипов или активного электричества уровень перезапускается.

## 🏗️ Архитектура проекта

Проект был переработан под структуру, похожую на **MVC**.

| Папка | Назначение |
|---|---|
| `Models/` | Хранение состояния игры: игрок, мир, порталы, куб, уровни |
| `Controllers/` | Игровая логика: движение, коллизии, порталы, меню, ловушки |
| `Views/` | Отрисовка мира, меню, настроек, подсказок и прицела |
| `Managers/` | Отдельные сервисы, например `SoundManager` |
| `Content/` | Текстуры, звуки, шрифты и игровые ресурсы |
| `Game1.cs` | Главный цикл игры: Initialize, LoadContent, Update, Draw |
| `Program.cs` | Точка входа в приложение |
